# 隐私与发布流程

本项目使用 [dsh-git-guard](https://github.com/impartOvo/dsh-git-guard)，本次使用版本 `35238cf488593ea622347b94d2c2eb12039a4183`。

发布副本只复制源码白名单。真实结果、浏览器配置、请求头、Cookie、会话文件、日志、桌面快捷方式和业务截图不进入发布目录。源测试改为占位符与合成数据后重新编译 EXE。

提交前运行扫描器 `--staged`，提交后运行 `--all`，推送时由原版 pre-push 钩子扫描待推内容。扫描错误和命中均阻止发布，不跳过钩子。本地业务词表不入库。

扫描器按其规则检测业务标识与凭据等文本，不保证理解全部业务数字或图片。发布包额外使用文件白名单，并检查第一方源码及 EXE 的文本字符串；第三方依赖来自已锁定的 npm 包和对应 Node 运行时，保留许可证。

新增功能或发布新版本时应重复扫描。不要提交 `.private/`、`results/`、真实账号材料和未经检查的截图。
